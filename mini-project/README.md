## About the Original Project

The tutorial shows how to build a chatbot using HTML, CSS, and JavaScript.

The original project has these features:

- A chat window that opens and closes
- You can type a message and the AI will answer
- You can send a picture with your message
- You can pick emojis from an emoji menu
- The chat window looks nice on phones too

---

## What I Added

I added two new features that are not in the tutorial video:

**1. Reset Button**
There is a button at the top of the chat. When you click it, all messages are deleted. The chat starts fresh.

**2. Save Chat History**
The chat is saved in the browser. If you close the page and come back, your old messages are still there. This uses local storage.

---

## How to Use

1. Open the `index.html` file in your browser
2. Click the green chat button at the bottom right
3. Type your message and press Enter (or click the send button)
4. The AI will answer your message
5. You can also click the emoji button or attach a picture
6. To clear all messages, click the refresh button at the top of the chat
